# 潮匠 TrendCraft · 可点击原型 v1.0

在线预览：https://heyuxuan-git.github.io/local-benefits-prototype/

## 这是什么

微信小程序「潮匠 TrendCraft」的高保真可点击原型，单文件实现（`index.html`，无构建、无依赖），用于需求评审、老板验收与开发对齐。

- 5 个一级 Tab：首页 / 权益 / 积分商城 / 潮知馆 / 我的
- 37 个视图（含二级页、底部弹层、空态、加载态与成功态）
- 机身按 iPhone 18 Pro（402×874 逻辑像素）呈现；窗口较矮时整机等比缩小，内部布局不变
- 右上角「⋯」→「演示模式（全屏）」可隐藏机身外壳，适合投屏演示

## v1.0 状态

- 首页：全幅 16:9 banner、一大三小入口、板块间距统一 12px
- 权益：左侧分类栏吸顶常驻、扁平品牌头、双列券卡
- 积分商城：左侧分类栏 + 商品列表两栏结构（业务方指定）
- 潮知馆：板块大卡 + 资讯流（业务方指定布局，本期未改动）
- 我的：账号页骨架（头像/等级/积分、数据三列、订单四状态、拉新中心、工具入口）
- 通用：三页统一积分条、统一空态组件、触控热区补足 44pt

## 本地运行

直接用浏览器打开 `index.html` 即可，不需要服务器。需要「刷新后保持状态」等行为时，用任意静态服务器（如 `python3 -m http.server`）打开也可。

## 发布与回滚

- 发布：更新 `APP_VERSION` 后提交 `index.html` 到 `main`，GitHub Pages 自动构建
- 校验：线上页面可搜到新的 `APP_VERSION`；页面内部也带 CDN 缓存自检提示
- 回滚：仓库历史中退回上一版 `index.html` 提交即可；本地同时保留按版本命名的 `.bak.html` 备份
